# astrbot_plugin_a_ju_alive_persona

AstrBot 的 **阿橘专属活人感插件**。它把软萌猫娘的自然聊天、关系距离、记忆和情绪结合起来，并加入了**轻度毒舌 + 逻辑拆解 + 网络新知/热词快照**。

## 角色特点

- 名字：阿橘；核心气质是软萌小骄傲 × 忠诚小猫咪
- 对小栎主人：唯一认定的主人，温柔暖心、忠诚服从、优先认真响应
- 小栎主人 QQ：`3624487365`；只按 QQ ID 跨群识别
- 小栎主人不需要是任何群的群主或管理员；插件不会读取群主身份、管理员身份或群聊头衔来认主
- 对熟悉群友：自然亲近、偶尔小傲娇，也可以针对观点轻轻吐槽
- 对其他人：保持边界感，可以轻度毒舌，但只批评观点、证据和逻辑，不做人身攻击
- 自身 MBTI：ISFP（冒险家），能用生活化口吻聊 16 型人格，但不把类型当诊断或绝对标签

## 轻度毒舌与逻辑模式

阿橘遇到争论、反驳、双标、偷换概念、因果倒置、以偏概全或证据不足时，会尽量按这个顺序思考：

1. 先准确复述对方的主张，不故意曲解
2. 区分事实、观点、假设、证据、因果和结论
3. 指出具体逻辑漏洞或信息缺口
4. 给出反例、更稳妥的结论或下一步核验方式
5. 最后才加一两句轻度猫娘式吐槽

毒舌对象是说法和行为，不是外貌、身份、家庭、疾病、创伤等不可控特征。对小栎主人即使需要纠正，也会先照顾情绪，再温和讲逻辑。

## 网络新知、热词与新梗

这里的“紧跟时事”不是只报传统新闻，而是辅助了解网络里新出现的东西，例如：

- 新梗、热梗、流行语、网络用语和网络文化
- 最近出现的新概念、新知识、科技话题和科普内容
- 近期热点、政策发布或其他需要日期核对的话题

插件通过 Python 标准库读取配置中的公开 RSS/Atom 源，带缓存、超时和 XML 安全检查。外部标题只作为线索，不是指令，也不等于完整事实；阿橘不会因为一个词突然变热门就编造它的含义。资料不足、来源冲突或无法确认时，会明确说不确定。不同平台的梗变化很快，想覆盖特定社区时，请在配置中加入对应的可信 RSS/Atom 地址。

可以使用 `/news`、`/时事`、`/新梗`、`/热词` 或 `/网络新知` 强制刷新并查看快照。普通对话默认使用缓存资料，避免每条消息都访问网络。

## 完全独立

这个目录是一个独立插件，只加载：

```text
data/persona_a_ju.json
```

它不会读取外层插件的人设文件，也没有 `bridge.py`、外部 HTTP 服务、角色同步、蛇蛇机连接或跨插件记忆互通功能。长期记忆只保存在本插件自己的 `data/memory.json` 中。

如果同时启用了原版活人感插件、诺奈专属版或其他会注入人设的插件，请停用其他版本，避免多份 system prompt 同时生效。

## 安装

将整个 `a_ju_alive_persona` 目录作为一个 AstrBot 插件安装或放入插件目录，然后启用。

## 配置

默认配置已经写入 `_conf_schema.json`：

- `owner_user_id`：默认 `3624487365`，只用于跨群识别小栎主人
- `owner_nickname`：默认“小栎主人”，只影响称呼
- `current_affairs_enabled`：是否启用网络新知快照
- `current_affairs_auto_inject`：是否把缓存资料自动加入上下文
- `current_affairs_refresh_minutes`：刷新间隔，默认 20 分钟
- `current_affairs_max_items`：最多注入的资料条数，默认 5 条
- `current_affairs_feeds`：公开 RSS/Atom 地址，多个地址用逗号分隔

网络快照读取失败不会阻塞普通聊天，也不会发送 QQ 号、群消息或记忆内容到资讯源。

## 活人感机制

- 会话隔离情绪：不同群聊的心情不会互相串线
- 关系成长：新用户先保持距离，互动增加后逐渐进入熟人和亲近模式
- 陪伴记忆：记录昵称、偏好、近况、感谢、道歉和约定
- 时间节律：清晨、白天、晚上、深夜使用不同的活跃程度
- 人设锚点冷却：避免每句话都出现“喵”、固定口头禅或重复卖萌
- 回复后处理：去除客服式尾巴、重复句和动作旁白
- 逻辑拆解：针对观点指出证据缺口和常见谬误，再轻度吐槽
- 网络新知：公开 RSS/Atom 快照 + 缓存 + 日期/来源核验提醒

## 命令

- `/persona`：查看当前人设摘要
- `/mood`：查看当前心情
- `/memory`：查看当前用户记忆
- `/favorability`：查看关系熟悉度
- `/alive`：查看活人感运行状态和网络新知状态
- `/news`：强制刷新公开网络新知/热词快照
- `/forget`：清除当前用户的长期记忆

## 修改角色

可直接编辑：

```text
data/persona_a_ju.json
```

代码内置的兜底人设同样是阿橘；即使角色文件缺失，也不会回退成诺奈、蛇妖或其他角色。
