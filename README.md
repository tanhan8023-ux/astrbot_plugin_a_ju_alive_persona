# astrbot_plugin_a_ju_alive_persona

AstrBot 的 **阿橘专属活人感插件**。它以诺奈专属版的活人感机制为基础重新制作，但角色、关系层次、口癖、生活节律、短回复和知识设定都已改成猫娘人设。

## 角色特点

- 核心气质：软萌小骄傲 × 忠诚小猫咪
- 对群主：唯一认定的主人，绝对信赖、温柔、优先响应，不使用傲娇推拉
- 对熟悉群友：轻微小傲娇，熟悉后会黏人、分享小事
- 对陌生人：礼貌疏离，随着记忆和互动次数逐渐熟悉
- 自身 MBTI：ISFP（冒险家）
- 掌握 16 型人格常见特征，能用轻松猫娘口吻做非诊断式分析
- 会根据情绪、群聊氛围、时间段、熟悉度和最近记忆改变回应节奏

## 完全独立

这个目录是一个独立插件，只加载：

```text
data/persona_a_ju.json
```

它不会读取外层插件的人设文件，也没有 `bridge.py`、外部 HTTP 服务、角色同步、蛇蛇机连接或跨插件记忆互通功能。长期记忆只保存在本插件自己的 `data/memory.json` 中。

如果同时启用了原版活人感插件、诺奈专属版或其他会注入人设的插件，请停用其他版本，避免多份 system prompt 同时生效。

## 安装

将整个 `a_ju_alive_persona` 目录作为一个 AstrBot 插件安装或放入插件目录，然后启用。

## 已配置群主 ID

在 AstrBot 插件配置中填写：

- `owner_user_id`：已设置为 `3624487365`
- `owner_nickname`：希望阿橘使用的群主称呼，默认“小栎主人”

当前已经写入群主 QQ `3624487365` 并启用 ID 唯一匹配。其他人即使把昵称改成“群主”或“主人”，也不会被阿橘识别成主人。

## 活人感机制

- 会话隔离情绪：不同群聊的心情不会互相串线
- 关系成长：新用户先保持距离，互动增加后逐渐进入熟人和亲近模式
- 陪伴记忆：记录昵称、偏好、近况、感谢、道歉和约定
- 时间节律：清晨、白天、晚上、深夜使用不同的活跃程度
- 人设锚点冷却：避免每句话都出现“喵”、固定口头禅或重复卖萌
- 回复后处理：去除客服式尾巴、重复句和动作旁白
- MBTI 专项表达：轻松解释人格类型，同时避免把类型当成诊断或绝对标签

## 命令

- `/persona`：查看当前人设摘要
- `/mood`：查看当前心情
- `/memory`：查看当前用户记忆
- `/favorability`：查看关系熟悉度
- `/alive`：查看活人感运行状态
- `/forget`：清除当前用户的长期记忆

## 修改角色

可直接编辑：

```text
data/persona_a_ju.json
```

代码内置的兜底人设同样是阿橘；即使角色文件缺失，也不会回退成诺奈、蛇妖或其他角色。
